# Сервис выдачи направлений

Публичная обезличенная копия версии **1.5.3**: браузерное приложение для формирования дополнительных направлений на ремонт фар, дисков и поставку деталей или ремкомплектов.

## Возможности

- Загрузка PDF перетаскиванием, распознавание двух поддерживаемых макетов и проверка данных.
- Учёт смещения, масштаба, поворота и фрагментации текстового слоя.
- Выбор страницы многостраничного файла; локальный ввод пароля защищённого PDF.
- Ручное заполнение с просмотром исходника для сканов и неизвестных макетов. OCR не используется.
- Выбор отдельных фар и дисков; количество деталей 1–999999. Стоимость задаётся за всё количество.
- Предпросмотр и сохранение PDF, подготовка письма для Outlook.
- Общий справочник JSON на том же сайте, формы редактирования сотрудников и СТО, экспорт черновика.

## Запуск

Проверено с Node.js 24 и npm 10.9.4. Для воспроизводимой установки используется явно указанная версия npm:

```sh
npx --yes npm@10.9.4 ci
npm run dev
```

Откройте `http://127.0.0.1:4173/`. При первом запуске создаётся локальный `directory.json` из демонстрационного образца. Существующий файл не перезаписывается.

Если установлен npm 11, используйте команду установки выше: на проверенной Windows-системе npm 11.19.0 отклонял lock-файл из-за платформенной необязательной зависимости. С npm 10.9.4 чистая установка выполнена успешно.

Демонстрационный вход: **Администратор**, пароль **123**. Также доступен **Сотрудник 001** с паролем **123**. Это специально созданные демонстрационные записи, не рабочие учётные данные.

## Сборка

```sh
npm run build
npm run preview
```

Для статического хостинга используйте содержимое `dist/`. Сборка включает локальный `directory.json`, если он есть, иначе демонстрационный `directory.example.json`. Не публикуйте сборку со своими данными без проверки содержимого.

Правки справочника в интерфейсе становятся общими только после загрузки экспортированного `directory.json` на ваш хостинг. Скачивание черновика само по себе не обновляет сайт.

## Проверки

Для генерации синтетических тестовых PDF дополнительно нужны Python 3 и ReportLab:

```sh
python -m pip install -r requirements-test.txt
npm run fixtures
npm test
npm run build
npm run check:publication
```

В репозитории 96 автоматических тестов. Две проверки по закрытым реальным документам из рабочего проекта не публикуются. Тестовые PDF генерируются локально и исключены из Git.

## Данные и ограничения

Рабочие сотрудники, ФИО, реальные пароли, справочники, исходные PDF и резервные копии в эту копию не входят. В коде и тестовых данных используются обозначения ролей и номеров записей вместо имён людей. Схема полей ФИО сохранена: пользователь может заполнить их в своей установке.

Вход проверяет хеш пароля в браузере; роли ограничивают интерфейс, но не являются серверной защитой. JSON на статическом сайте доступен посетителям. Для настоящего разграничения доступа нужен серверный механизм авторизации.

Документы и пароль PDF обрабатываются локально. Предельный размер файла — 20 МБ; автоматический поиск охватывает первые 50 страниц, остальные можно выбрать вручную. Универсальное распознавание произвольного макета не гарантируется; неуверенные значения остаются пустыми с предупреждением.

Публикация этого репозитория не обновляет и не заменяет действующую рабочую установку.
